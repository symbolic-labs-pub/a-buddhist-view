## Kangling (Cuerno Ritual)

*Este símbolo aún no tiene contenido completo.*

El **kangling** es un cuerno ritual tradicionalmente hecho de un fémur humano. Se utiliza en prácticas budistas tibetanas, especialmente en rituales chöd, para recordar la impermanencia y superar el apego al cuerpo físico.
