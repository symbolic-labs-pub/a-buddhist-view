## Torma

*Este símbolo aún no tiene contenido completo.*

Los **torma** son ofrendas rituales hechas de harina de cebada y mantequilla. Se moldean en formas específicas y se utilizan en ceremonias budistas tibetanas como representaciones simbólicas de ofrendas a deidades y como soportes para la práctica.
