## Προπαρασκευαστικές Πρακτικές

Στο Vajrayāna, τα **Ngöndro** (προπαρασκευαστικές πρακτικές) δεν είναι εισαγωγικές ασκήσεις που κάποιος τελειώνει και μετά ξεχνά. Είναι **πλήρη μονοπάτια απελευθέρωσης**, παγκοσμίως ισχυρές και ικανές να φέρουν αφύπνιση από μόνες τους.

Αποτελούνται από τέσσερεις κύριες πρακτικές: προσκυνήσεων, αγνοσαγωγί, mandala offering, και guru yoga. Κάθε ένα καθαρίζει συγκεκριμένα εμπόδια και ωριμάζει συγκεκριμένες ιδιότητες του νου.
