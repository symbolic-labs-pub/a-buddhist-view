## Σύμβολα

Στον Βουδδισμό, κάθε σύμβολο είναι μια **συντομογραφία για μια ολόκληρη εποπτεία**, όχι ένα προσδεθημένο αντικείμενο. Το λουλούδι lotus, το mala, το dharma wheel—αυτά δεν είναι διακοσμητικά. Κάθε ένα δεν είναι ένας δείκτης προς μια ειδική αλήθεια του Βουδδισμού.

Η κατανόηση αυτών των συμβόλων μαθαίνει τον ασκούμενο να βλέπει τη διδασκαλία ακόμα και σε απλά πράγματα—και να μαθαίνει να διαβάζει τη γλώσσα με την οποία ο Βουδδισμός μιλάει.
