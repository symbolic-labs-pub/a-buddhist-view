## Παρόν και Ιστορία

Ο Βουδδισμός δεν είναι ένα ιστορικό δενδρίτη που κατακρεουργείται από το πέρασμα του χρόνου. Είναι μια ζώσα κόνιμη συνέχεια—με ρίζες που χρονολογούνται πολλές χιλιάδες χρόνια στον ιστορικό Βούδδα **Siddhārtha Gautama**, αλλά διατηρώντας την αγνή γραμμή της διδασκαλίας και της πρακτικής σε ψηφοφορίες της Ασίας και πέρα.

Κάθε παράδοση που προκύπτει—Theravāda, Mahāyāna, Vajrayāna—δεν αποτελεί αντίχρησιν. Μάλλον, κάθε είναι ένας τρόπος να λύνετε τις ίδιες διδασκαλίες σε διαφορετικούς πολιτισμούς, κατανόησης, και εποχές, διατηρώντας τον πυρήνα: η δυνατότητα αφύπνησης είναι στις χέρια κάθε ατόμου.
