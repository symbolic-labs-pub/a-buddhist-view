## Mahamudra και Dzogchen

Τα **Mahamudra** και **Dzogchen** είναι δύο από τις ψηλότερες και πιο άμεσες μέθοδοι του Vajrayāna Βουδδισμού για τη αφύπνιση. Και οι δύο δίδασκουν ότι το νου στη δική του φύση είναι ήδη αφυπνισμένο—οι πρακτικές είναι σχεδιασμένες απλώς για να αποσαφηνίσουν αυτή την πραγματικότητα.

Μέσω του άμεσου διδάσκαλό του ειδικευμένου δασκάλου, ο ασκούμενος μαθαίνει να αναγνωρίσει τη φύση του νου και να επιτρέψει στη αφύπνιση να εκφράσει τη δική του αυθεντική σοφία.
