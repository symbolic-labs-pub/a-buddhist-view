Budizm di 2500+ salan de ji Hindistanê di vî Tibetê, Çinê, Japonya û Evrupayê rû da.

**Rêbazên Bingehîn:**
- Theravāda (Asya Ş.)
- Mahāyāna (Çin, Japonya, Vietnam)
- Vajrayāna (Tibet, Mongol)

**Niha:**
Budizm di gundê xanedenî de yek din dide û pratikenavan rastî navê xwe derketina dike.
