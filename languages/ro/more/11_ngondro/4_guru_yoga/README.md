### **Insatisfacția Samsāra → Guru Yoga**

În înțelegerea Kagyu a **Ngöndro**, **a patra practică** completează *întoarcerea exterioară a minții* și *deschide calea interioară*. Este balama unde **renunțarea maturizează în recunoaștere directă**.

---

## 1) Insatisfacția Samsāra (Duḥkha a Existenței Ciclice)


Această contemplare **nu este pesimism** și nici judecată morală. Este *diagnostic*.

### Ce este recunoscut

* **Toate stările condiționate sunt instabile**
  Plăcerea decade, securitatea erodează, identitatea se fragmentează.
* **Optimizarea nu echivalează eliberarea**
  Circumstanțe mai bune ≠ libertate față de naștere, îmbătrânire, boală, moarte.
* **Controlul este structural imposibil**
  Chiar succesul întărește atașamentul la ceea ce se va schimba.

> Perspectiva cheie: **Samsāra nu este stricat — funcționează exact cum este proiectat.**

A încerca să perfecționezi samsāra este ca a încerca să stabilizezi un val rămânând în ocean.

### De ce contează

Până când această perspectivă este **internalizată emoțional**, practica rămâne instrumentală:

* [meditația](../../08_lineage/README.md) devine auto-îmbunătățire,
* [etica](../../01_core_teachings/the_noble_eightfold_path/README.md#2-ethical-conduct-śīla) devine management de reputație,
* devoțiunea devine proiecție.

A patra contemplare **taie ultima speranță** că samsāra poate fi rafinată în [trezire](../../10_concepts/README.md#3-enlightenment-bodhi-awakening).

Acea tăietură creează *spațiu*.

---

## 2) Guru Yoga (Punctul de Cotitură)


Când speranța în samsāra se prăbușește, mintea este în sfârșit *disponibilă*.

Guru Yoga nu este adorație.
Este **antrenament de recunoaștere**.

### Ce Înseamnă De Fapt "Guru"

* Guru-ul **nu este o personalitate**
* Guru-ul **nu este o autoritate externă**
* Guru-ul este **funcția vie a minții trezite**, făcută *recunoscută*

În Kagyu, guru-ul este **interfața** între:

* [conștiință](../../10_concepts/README.md#2-awareness-rigpa-vijñāna-knowing) obișnuită neantrenată
* și propria sa natură deja-trezită

---

## 3) Devoțiunea ca Tehnologie Cognitivă


Devoțiunea aici este **aliniere de precizie**, nu emoție.

Ea îndeplinește trei funcții:

### 1. Prăbușirea separării subiect–obiect

* "Învățător" și "elev" sunt roluri provizorii
* Guru Yoga dizolvă credința că trezirea este *în altă parte*

### 2. Ocolirea strategiei-ego

* Egoul nu poate imita devoțiunea fără să se dezvăluie
* Sinceritatea expune fixarea mai rapid decât analiza

### 3. Transmiterea structurii, nu informației

* Realizarea este **conștiință structurată**
* Guru Yoga antrenează mintea la acel model

Acesta este motivul pentru care Kagyu pune accent pe **continuitatea liniei** peste noutatea filosofică.

---

## 4) Al 17-lea Karmapa Thaye Dorje În Acest Context


În practica Kagyu contemporană, **Al 17-lea Karmapa Thaye [Dorje](../../09_symbols/02_dorje/README.md#dorje-vajra--explicat-conform-învățăturilor-budiste)** funcționează ca un **punct de referință viu** al integrității liniei.

Clarificări importante:

* El **nu este meditat ca un zeu**
* El **nu este un mântuitor**
* El reprezintă **transmisia neîntreruptă a realizării [Mahāmudrā](../../04_kayas/mahamudra_and_dzogcsen/README.md#mahāmudrā-nature-of-mind-སེམས་ཀྱི་གནས་ལུགས་)**

Principiul Karmapa este *structural*, nu personal:

> Oriunde se manifestă realizarea autentică, **mintea recunoaște mintea**.

---

## 5) De Ce Vine Ultimă Guru Yoga În Ngöndro


Secvența contează.

| Fără practici anterioare  | Cu practici anterioare         |
| ------------------------- | ------------------------------ |
| Devoțiunea devine fantezie| Devoțiunea devine recunoaștere |
| Guru devine idealizat     | Guru devine transparent        |
| Practica întărește sinele | Practica dizolvă sinele        |

[Insatisfacția](../../02_from_ignorance_to_awakening/2_the_four_noble_truths/README.md#1-there-is-suffering--dukkha) Samsāra **golește paharul**.
Guru Yoga **arată ce a fost mereu acolo**.

---

## 6) Perspectiva Esențială a Practicii a Patra


> **Eliberarea nu se realizează prin repararea experienței,
> ci prin recunoașterea naturii celui care experimentează.**

Guru Yoga nu adaugă nimic.
Ea **îndepărtează obstrucția finală**: credința că trezirea aparține altcuiva.

---

### Rezumat pe o linie Kagyu

**Când samsāra este văzută ca nefuncțională, devoțiunea devine funcțională — și recunoașterea devine inevitabilă.**
