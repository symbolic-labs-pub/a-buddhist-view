### Mandala — explicată conform învățăturilor budiste

![mandala](../../../../../more/09_symbols/07_mandala/mandala.png)

---

În budism (în special [Vajrayāna](../../05_yanas/README.md#4-vajrayāna-tantrayāna-mantrayāna---the-diamond-vehicle)), o **mandala** nu este un ornament sau o imagine simbolică. Este un **model funcțional al cogniției trezite**—un mediu de antrenament pentru minte.

---

## 1. Ce este o mandala (ontologic)

O mandala este o **reprezentare a minții iluminate ca structură**.

* **Centrul** reprezintă conștiința trezită [(adesea un Buddha sau yidam)](../../10_concepts/README.md#2-awareness-rigpa-vijñāna-knowing).
* **Palatul înconjurător** reprezintă calitățile stabilizate ale minții.
* **Porțile, pereții și cercurile** reprezintă discernământul, [etica](../../01_core_teachings/the_noble_eightfold_path/README.md#2-ethical-conduct-śīla) și protecția împotriva confuziei.
* **Inelele exterioare** (foc, [vajra](../02_dorje/README.md#dorje-vajra--explained-according-to-buddhist-teachings), [lotus](../08_lotus/README.md#the-lotus-in-buddhist-teaching)) reprezintă purificarea obscurărilor.

În termeni budişti, mandala este o **manifestare a [originii dependente](../../02_from_ignorance_to_awakening/3_dependent_origination/README.md#the-twelve-links-the-classic-formulation) văzută clar**—modul în care [înțelepciunea](../../01_core_teachings/the_noble_eightfold_path/README.md#1-wisdom-paññā), [compasiunea](../../02_from_ignorance_to_awakening/7_compassion/README.md#compassion-as-a-structural-principle-in-buddhist-teaching), claritatea și activitatea apar împreună când ignoranța este absentă.

> Mandala arată **cum arată mintea când nu mai este fragmentată**.

---

## 2. De ce contează geometria

Geometria mandala nu este estetică—este **inginerie cognitivă**.

* Simetria antrenează **conștiință non-preferențială**
* Axele antrenează **claritate fără direcție**
* Repetitivitatea stabilizează **atenția**
* Proporțiile codifică **facultăți echilibrate**

Acesta este motivul pentru care mandala sunt precise până la milimetru în practica tradițională.
O mandala distorsionată antrenează o minte distorsionată.

> În Vajrayāna, **forma este folosită deliberat pentru a reconecta percepția**.

---

## 3. Practica de vizualizare (etapa de generare)

Când un practicant vizualizează o mandala:

1. Percepția obișnuită se dizolvă
2. Spațiul devine luminos și structurat
3. Mandala apare **din [golime](../../10_concepts/01_emptiness/README.md#emptiness-śūnyatā-in-vajrayāna-buddhism)**
4. Practicantul o locuiește din interior

Acest lucru **nu** înseamnă "imaginarea a ceva frumos."

Antrenează:

* Stabilitate fără atașament
* Claritate fără efort
* Identitate fără ego

În cele din urmă, **granița dintre observator și mandala se prăbușește**.

> Mandala nu este *văzută*—este *recunoscută*.

---

## 4. Dizolvare și impermanență (etapa de completare)

După construcție, mandala este **dizolvată**.

Mandala de nisip sunt distruse deliberat pentru a demonstra:

* Toate formele sunt condiționate
* Chiar structurile sacre sunt goale
* Atașamentul la puritate este tot atașament

Acest lucru antrenează direct **non-atașamentul la realizarea însăși**.

> Cea mai mare greșeală în budism este atașamentul la experiențele de [trezire](../../10_concepts/README.md#3-enlightenment-bodhi-awakening).

---

## 5. De ce mandala este numită "arhitectură cognitivă"

Pentru că face ceea ce filosofia nu poate:

* **Restructurează percepția**, nu credința
* Integrează emoția, viziunea, corpul și atenția
* Codifică etica, înțelepciunea și compasiunea simultan

O mandala este un **model funcțional al minții după ce iluzia a fost îndepărtată**.

Acesta este motivul pentru care este folosită doar cu pregătire corespunzătoare:

* etică (śīla)
* [concentrare (samādhi)](../../01_core_teachings/the_noble_eightfold_path/README.md#8-right-concentration-sammā-samādhi)
* perspectivă (prajñā)

Fără acestea, practica mandala devine fantezie estetică.

---

## 6. Punctul cel mai profund

În cele din urmă, învățătura budistă afirmă:

* Mandala **nu este în exterior**
* Zeitatea **nu este alta**
* Palatul este **propria ta cogniție, văzută clar**

Când acest lucru este înțeles:

> Fiecare percepție devine o mandala.
> Fiecare moment devine spațiu sacru.

---

### Rezumat (într-o propoziție)

**O mandala este utilizarea disciplinată a formei pentru a dezvălui conștiința fără formă—antrenând mintea să își recunoască propria structură trezită, apoi să o lase să plece.**
