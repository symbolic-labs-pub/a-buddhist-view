[![impermanence](impermanence.png)](https://github.com/symbolic-labs-pub/a-buddhist-view/blob/master/more/01_core_teachings/impermanence/README.md#all-conditioned-things-are-impermanent)
**(Pāli: *sabbe saṅkhārā aniccā*)**

### 1. Ce înseamnă cu adevărat *saṅkhārā*

În învățătura budistă, *saṅkhārā* se referă la **toate fenomenele condiționate**—orice:

* apare datorită **cauzelor și condițiilor**
* depinde de alți factori pentru a exista
* este **fabricat, compus sau construit**

Aceasta include:

* materia fizică (corpuri, obiecte, medii)
* formațiuni mentale (gânduri, emoții, intenții)
* construcții sociale și existențiale (roluri, identități, instituții, credințe)

Realitatea necondiționată (*asaṅkhata*), prin contrast, se referă doar la **Nibbāna**—ceea ce nu apare sau încetează.

---

### 2. Impermanența (*anicca*) este structurală, nu accidentală

Conform analizei lui Buddha asupra realității:

> Orice este condiționat **trebuie să se schimbe**, deoarece condițiile care îl susțin sunt ele însele instabile.

Aceasta nu este o observație poetică—este o **înțelegere asemănătoare unei legi** asupra cauzalității (*paṭicca-samuppāda*, [originea dependentă](../../02_from_ignorance_to_awakening/3_dependent_origination/README.md#cele-douăsprezece-verigi-formularea-clasică)).

* Când cauzele se schimbă → efectele se schimbă
* Când condițiile de susținere se dizolvă → fenomenul încetează

Astfel, impermanența **nu este ceva ce se întâmplă lucrurilor**
→ este **ceea ce sunt lucrurile**.

---

### 3. Impermanență la toate scările

**Fizic**

* Corpurile îmbătrânesc, se degradează și mor
* Munții se erodează, stelele se sting
* Civilizațiile cresc și se prăbușesc

**Mental**

* Gândurile pâlpâie moment de moment
* Emoțiile apar, ating apogeul și se dizolvă
* Intențiile se schimbă cu condițiile

**Existențial**

* Identitatea este un proces, nu un nucleu
* Rolurile există doar relațional
* Credințele depind de context, cultură și stare mentală

În analiza budistă timpurie, chiar și un singur moment de experiență este deja **în flux**.

---

### 4. De ce impermanența duce la suferință (*dukkha*)

Buddha **nu** a spus că impermanența însăși este [suferință](../../02_from_ignorance_to_awakening/2_the_four_noble_truths/README.md#1-există-suferință--dukkha).

Suferința apare pentru că:

* **ne atașăm** la ceea ce se schimbă
* cerem stabilitate de la ceea ce nu o poate oferi
* căutăm control asupra a ceea ce nu este posibil de deținut

> "Ceea ce este impermanent este nesigur.
> Ceea ce este nesigur este nesatisfăcător."

Acesta este motivul pentru care *anicca → dukkha → anattā* (impermanență → nesatisfacție → [non-sine](../../02_from_ignorance_to_awakening/1_the_three_marks_of_existence/README.md#3-non-sine-anattā)) formează un lanț unic de înțelegere.

---

### 5. Înțelegerea profundă, nu credința, este remediul

Budismul nu cere acord intelectual.
El cere **vedere directă** (*[vipassanā](../../05_yanas/shikantaza_and_vipassana/README.md#1-vipassanā-theravāda-înțelegere-profundă---extragerea-caracteristicilor-de-reificare)*).

Când impermanența este văzută clar:

* atașamentul se slăbește în mod natural
* frica de pierdere se diminuează
* dorința își pierde puterea
* identitatea se înmoaie

Libertatea apare **nu prin oprirea schimbării**,
ci prin **a nu mai rezista la ea**.

---

### 6. Impermanența este eliberatoare, nu pesimistă

Din perspectiva budistă:

* Dacă lucrurile ar fi permanente → eliberarea ar fi imposibilă
* Deoarece lucrurile se schimbă → transformarea este posibilă
* [Trezirea](../../10_concepts/README.md#3-iluminarea-bodhi-trezirea) însăși depinde de impermanență

> Impermanența este **deschiderea** prin care libertatea intră.

---

În cuvintele atribuite **Gautama Buddha**:

> "Toate lucrurile condiționate sunt impermanente.
> Când cineva vede acest lucru cu [înțelepciune](../the_noble_eightfold_path/README.md#1-înțelepciune-paññā),
> se îndepărtează de suferință."
