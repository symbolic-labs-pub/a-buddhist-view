### Ce spune efectiv învățătura

**Natura Buddha** (*Sanskrit: Tathāgatagarbha, "pântecele/embrionul unui Buddha"*) învață că **toate ființele simțitoare posedă capacitatea intrinsecă de a se trezi**.
Aceasta **nu** înseamnă că toată lumea este deja iluminată într-un sens convențional. Înseamnă că **condițiile pentru [iluminare](../../10_concepts/README.md#3-iluminarea-bodhi-trezirea) sunt deja prezente**, chiar dacă sunt obscurate.

În limbajul clasic [Mahāyāna](../../05_yanas/README.md#limitarea-din-perspectiva-mahāyāna):

> Trezirea nu este *creată* — este *descoperită*.

Această învățătură apare cel mai clar în sutrele Mahāyāna precum **Tathāgatagarbha Sūtra**, **Śrīmālādevī Siṃhanāda Sūtra** și tradițiile comentariale ulterioare precum **Mahāparinirvāṇa Sūtra**.

---

### Ce **nu** este natura Buddha

O clarificare critică în interpretarea budistă ortodoxă:

* ❌ **Nu este un suflet (ātman)**
* ❌ **Nu este un sine etern**
* ❌ **Nu este o substanță metafizică**

Dacă ar fi un sine fix, ar contrazice **[non-sinele (anattā)](../1_the_three_marks_of_existence/README.md#3-non-sine-anattā)** și **golirea (śūnyatā)**.

În schimb, natura Buddha este cel mai bine înțeleasă ca:

> **Golirea minții care face posibilă trezirea**

Cu alte cuvinte:
Pentru că mintea **nu este fixă**, **nu este în mod inerent pângărită** și **nu este deținută**, se poate trezi.

---

### De ce metaforele contează

Metaforele clasice pe care le-ai enumerat nu sunt suplimente poetice — sunt **instrumente de precizie** pentru a preveni neînțelegerea.

#### 🟡 *Aur acoperit de murdărie*

* Aurul nu este **niciodată deteriorat**
* Murdăria este **adventice**, nu esențială
* Curățarea nu *creează* aur — îl **dezvăluie**

➡ Pângăririle (lăcomie, ură, iluzie) sunt **condiții temporare**, nu natura minții.

#### 🌱 *Sămânță în interiorul unei capsule de lotus*

* [Lotusul](../../09_symbols/08_lotus/README.md#lotusul-în-învățătura-budistă) crește din noroi
* Sămânța conține deja *forma* florii
* Condițiile (apă, lumină, timp) sunt necesare

➡ Practica este **necesară**, dar funcționează prin **permiterea maturării**, nu prin invenție.

#### ☁️ *Cer clar în spatele norilor*

* Norii se mișcă, cerul nu
* Cerul nu este "îmbunătățit" când norii se împrăștie
* Vizibilitatea se schimbă, nu esența

➡ Gândurile și emoțiile obscurizează [conștientizarea](../../10_concepts/README.md#2-conștientizare-rigpa-vijñāna-cunoaștere), dar **nu o definesc**.

### Cum se potrivește cu golirea (Śūnyatā)

La prima vedere, natura Buddha poate suna ca o contradicție a [golirii](../../10_concepts/01_emptiness/README.md#golirea-śūnyatā-în-budismul-vajrayāna). Istoric, aceasta a cauzat dezbateri reale.

Rezoluția folosită de tradițiile majore:

* **Golirea** descrie **absența existenței inerente**
* **Natura Buddha** descrie **absența obstrucției inerente**

> Pentru că mintea este goală de esență fixă, este capabilă de trezire.

Zen și Madhyamaka formulează adesea acest lucru cu grijă:

> Natura Buddha este **golirea experimentată fără frică**.

### De ce există această învățătură (funcția sa)

Natura Buddha este **medicină pedagogică**, prescrisă pentru pericole specifice:

#### 1. Contracararea deznădejdii

Fără această învățătură, practicanții pot concluziona:

* "Sunt prea distrus"
* "Mintea mea este fără speranță"
* "Iluminarea este pentru călugări, sfinți sau elite"

Natura Buddha respinge direct acest lucru.

#### 2. Contracararea elitismului spiritual

În același timp, previne:

* Afirmații de superioritate inerentă
* Aroganță de linaj
* Practicanți "aleși"

Dacă **toată lumea are natura Buddha**, nimeni nu deține trezirea.

#### 3. Susținerea compasiunii

Dacă toate ființele au capacitatea de a se trezi, atunci:

* Nicio ființă nu este de aruncat
* Nicio ființă nu este fundamental rea
* [Compasiunea](../7_compassion/README.md#compasiunea-ca-principiu-structural-în-învățătura-budistă) devine rațională, nu sentimentală

---

### Cum se raportează practica la natura Buddha

Practica nu înseamnă *adăugarea* purității — înseamnă **îndepărtarea obscurărilor**.

| Practică             | Funcție                          |
| -------------------- | --------------------------------- |
| [Etică (śīla)](../../01_core_teachings/the_noble_eightfold_path/README.md#2-conduită-etică-śīla)        | Stabilizează condițiile             |
| [Meditație ([samādhi](../../08_lineage/README.md))](../../03_the_path_to_end_suffering/README.md#acțiune-corectă) | Calmează turbulența obscurizantă        |
| [Înțelepciune (prajñā)](../../01_core_teachings/the_noble_eightfold_path/README.md#1-înțelepciune-paññā)      | Vede prin identificarea falsă |

Acesta este motivul pentru care multe tradiții spun:

> Calea nu duce *la* natura Buddha —
> duce *de la confuzie la recunoaștere*.

---

### Un rezumat doctrinar concis

* Natura Buddha afirmă **capacitatea universală de trezire**
* **Nu** reintroduce un sine
* Se armonizează cu golirea când este înțeleasă corect
* Previne nihilismul *și* aroganța
* Reconfigurează practica ca **dezvăluire mai degrabă decât construcție**

> Nu devii ceva nou.
> Încetezi să te confunzi cu ceva mai mic.
